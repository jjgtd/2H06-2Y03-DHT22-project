My main contribution was designing the PCB and creating the CAD enclosure. I used EasyEDA to lay out the board and route the traces between the ESP32 and DHT22. My biggest challenge was wiring and routing — some traces were too close together and crossed over, which could have caused short circuits. I fixed this by rearranging the components, using wider power traces, and checking the design rules before exporting. I also added ventilation slots to the enclosure so the DHT22 reads humidity accurately. If I had more time, I would make the trace layout more compact. This project taught me that PCB design needs patience and careful checking.
